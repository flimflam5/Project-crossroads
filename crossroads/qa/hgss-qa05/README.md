# QA05 evidence

All game PNGs are unretouched native240x160 mGBA captures. comparisons.html pairs
selected views with linked original HGSS reference mosaics; different projections
and coverage are explicitly labeled. It also shows exact QA04/QA05 old-save Continue
views at Bell9F(7,3). This is developer evidence, not owner visual acceptance.

results.json records the tested ROM SHA. Tour/collision JSONs and text logs record
actual controller checks. No saves, snapshots or ROMs are committed in this folder.
Fly video:15fps captures every4 emulated frames. Trunk video:30fps captures every2
frames; order north/west/east/south, pressing into the root then releasing. Videos
are silent. See ../../hgss/ECRUTEAK_QA05.md for adaptations and unplayed modes.

Sources: public pret/pokeheartgold geometry facts with blob SHAs; HGSS reference
images linked to Bulbagarden Archives. Their original graphics are reference-only,
not embedded in the ROM. New graphics use original GBA art/native project assets.
