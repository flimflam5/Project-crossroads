Source `3f20e0cb9f1650a3e18303802bb5e423dfed58e6`; tested ROM SHA-256 `a5b9b82db937ed12bcdd2fae571f99843491c78150efa1f2b60806e9e428ef75`. Files in this directory are native mGBA screenshots, controller recordings, and sanitized actual results for this candidate unless explicitly labelled rejected. None are owner Delta or visual acceptance.

Four genuine QA10 old-position batteries were produced by ordinary controller movement and native in-game Save, then cold-Continued on this candidate. Their source batteries were not modified and are not included. The sampled positions cover previously blocked (22,7), newly elevation-4 (25,18), newly active threshold (19,13), and an unaffected (5,14) negative control. For each, decoded party, boxes, flags, starter and inventory were checked; save location, visibility and actual walking away were exercised. This does not establish safety for every old save. The host model separately evaluates the old positions with mocks, which is not emulator coverage of each position.

The actual old (22,7) save restored a stale prior resident at (19,15) in rejected ROM `69429b2d6df08d2757da8c92c94aa4a5316588626f583056856ab8fb30358ef7`, obstructing the new cave approach; the second rejected image shows the old threshold save landing immediately above that resident. The `rejected-69429/` screenshots document that failure, not this delivery candidate. The R2 `resident-migration-observation.json` records direct inspection of the corrected saved and live NPC at (21,25).

The first strict R2 ordinary-floor sprite visibility attempt was obscured by moving rain, not static terrain. Its frozen state was sampled for 60 native frames; `visibility-analysis/visibility.json` and frames 00/02 record the rain streak and a subsequent full 192/192 visible frame. The controller rerun retains rejected-frame audits, restricts native grass masking to feet, and still requires an actual fully visible ordinary-floor frame.

The controller test exercised reciprocal Azalea and Union Cave transitions, 39 sampled collision bumps, four directional ledge jumps, the original resident, the non-battling Hiker, two trees and both signs, then native Save/cold Continue. All interactions were checked for no changes to decoded inventory, flags, party or boxes. The tree-specific checks verified both custom graphics IDs and palette tag against the linked ROM, live OBJ VRAM and hardware/unfaded palettes before interaction and after cold Continue. Runtime map tiles, compiled assets and palette banks were independently compared to source; primary animated tiles and exhaustive collision are outside this check.

Title, all three starter grants/duplicate guards, Fly to ten destinations, Surf, bikes, fishing, disembark, Joe battle-back graphics and a first-loss battle were tested on the same ROM with explicitly disclosed fixtures. The starter harness skips the opening; gear and survey access were test-only. Dive, watering, decoration and VS Seeker were not activated. Johto-wide, Union Cave/Ruins and owner visual QA remain unfinished.
